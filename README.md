# CodeAlpha_Hangman

A simple text-based Hangman game built in Python — CodeAlpha Python Internship Task 1.

## 🎮 Features
- 5 predefined words (randomly chosen)
- Maximum 6 incorrect guesses allowed
- ASCII art hangman display
- Input validation (single letter only, no repeats)

## 🛠️ Concepts Used
`random`, `while` loop, `if-else`, strings, lists

## ▶️ How to Run
```bash
python hangman.py
